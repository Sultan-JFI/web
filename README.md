# وب‌سایت فلاسک با پنل تنظیمات — رانفلر

گالری تصاویر مذهبی با آپلود، دسته‌بندی، صفحه تکی تصویر و QR Code.

استقرار روی پروژه `starter` سرویس `basic` (id پروژه 36795، id آیتم 85579).

## استقرار

از ریشه همین پوشه:

```
runflare deploy --project-id 36795 --item-id 85579
```

یا بعد از اولین دیپلوی: `runflare deploy -y`

با اتصال گیت‌هاب و auto-pull، هر push به `main` خودکار دیپلوی می‌شود.

## متغیرهای محیطی (پنل رانفلر: تنظیمات سرویس ← متغیر محیطی)

| نام | توضیح |
|-----|--------|
| `PANEL_PASSWORD` | فقط برای مقدار اولیه؛ رمز واقعی در settings هش می‌شود |
| `SECRET_KEY` | کلید امضای سشن (ثابت نگه دارید؛ در غیر این صورت در settings ذخیره می‌شود) |
| `PORT` | پورت گوش‌دادن (پیش‌فرض 8000؛ با Target Port شبکه یکی باشد) |
| `DATA_ROOT` | مسیر دیسک پایدار (مثلاً `/data`) |
| `PUBLIC_BASE_URL` | آدرس عمومی سایت برای لینک QR (مثلاً `https://sultan-kdns.ir`) |
| `SESSION_COOKIE_SECURE` | `1` (پیش‌فرض) برای HTTPS؛ روی HTTP محلی `0` |

## ماندگاری تنظیمات و آپلود (دیسک)

طبق مستندات رانفلر، برای فایل‌های بعد از دیپلوی باید دیسک تعریف شود:

1. تنظیمات سرویس ← مدیریت دیسک ← اضافه کردن دیسک
2. مسیر: ترجیحاً **`/data`** (مطلق، از `/` شروع شود)
3. حجم دلخواه را ذخیره کنید

سپس در متغیر محیطی:

```
DATA_ROOT=/data
```

بدون دیسک، بعد از هر ریستارت آپلودها و تنظیمات پاک می‌شوند.

پوشه‌های داخل دیسک به‌صورت خودکار ساخته می‌شوند:
- `uploads/` و `uploads/thumbnails/`
- `settings.json` و `gallery.db`

## صفحه‌ها

| مسیر | توضیح |
|------|--------|
| `/` | گالری عمومی |
| `/image/<id>` | صفحه تکی تصویر (مقصد QR) |
| `/image/<id>/qr.png` | دانلود QR Code همان تصویر |
| `/panel` | پنل مدیریت |
| `/health` | سلامت سرویس (JSON) |
