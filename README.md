# وب‌سایت فلاسک با پنل تنظیمات — رانفلر

استقرار روی پروژه `starter` سرویس `basic` (id پروژه 36795، id آیتم 85579).

## استقرار
از ریشه همین پوشه:

    runflare deploy --project-id 36795 --item-id 85579

یا بعد از اولین دیپلوی: `runflare deploy -y`

## متغیرهای محیطی (پنل رانفلر: تنظیمات سرویس ← متغیر محیطی)
- `PANEL_PASSWORD` — رمز ورود به پنل تنظیمات (پیش‌فرض: admin123)
- `SECRET_KEY` — کلید امضای سشن
- `PORT` — پورت گوش‌دادن (پیش‌فرض 8000؛ باید با Target Port شبکه سرویس یکی باشد)

## ماندگاری تنظیمات (دیسک)
تنظیمات در `data/settings.json` ذخیره می‌شود. در پنل رانفلر:
تنظیمات سرویس ← مدیریت دیسک ← اضافه کردن دیسک → مسیر: `data` و حجم دلخواه را ذخیره کنید.
بدون دیسک، بعد از هر ریستارت تنظیمات به حالت پیش‌فرض برمی‌گردد.

## صفحه‌ها
- `/` صفحه اصلی (از تنظیمات پنل پیروی می‌کند)
- `/panel` پنل تنظیمات (ورود با رمز)
- `/health` بررسی سلامت (JSON)
